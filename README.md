# Neural Network Solver for Integral Equations

Програмна реалізація до курсової роботи, присвяченої наближеному розв'язуванню інтегральних рівнянь за допомогою штучних нейронних мереж. Дослідження проводиться на прикладі крайової задачі Діріхле для рівняння Лапласа в частково необмеженій області.

## Опис математичної моделі

Використовується підхід, споріднений з Physics-Informed Neural Networks (PINN). Задача зводиться до інтегрального рівняння першого роду з логарифмічною особливістю за допомогою функції Гріна. 

Замість дискретизації рівняння та розв'язання щільної СЛАР (як у класичному методі Nyström), невідома густина потенціалу $\mu(t)$ апроксимується за допомогою багатошарового перцептрона. Мережа навчається "на льоту" (без використання зовнішніх датасетів), мінімізуючи нев'язку інтегрального рівняння (MSE Loss) у заданих точках колокації. Особливість ядра обробляється за допомогою вагових функцій тригонометричних квадратур.
